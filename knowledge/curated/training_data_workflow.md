# 多语言语音训练数据生成与质检流程

## 安全说明

本条目只保留可复用的流程知识。原材料中的服务器地址、登录账号、人员姓名、SSH 配置和内部目录均已删除。实际运行凭据必须通过批准的内部渠道获取，不能从知识检索结果中返回。

## 生成前配置

一次生成任务至少应记录：

- 唯一运行标签 `run_tag`；
- 输入模板版本与校验和；
- 目标语言列表；
- 目标 Domain 列表；
- 各 Domain 的泛化数量；
- TTS 生成数量；
- 需要合并的现有数据集版本；
- 输出位置和预期文件名；
- 发起时间、执行程序版本和任务状态。

## 推荐流程

1. **预检查**：确认模板存在、语言和 Domain 在允许列表中、输出标签未被使用。
2. **配置冻结**：保存本次配置快照，避免运行期间被覆盖。
3. **互斥检查**：同一共享执行环境一次只运行一个会写同一输出位置的任务。
4. **启动生成**：由受控脚本启动，并将标准输出和错误输出写入运行日志。
5. **过程监控**：记录阶段进度、失败原因和重试次数；不能仅依据进程存在判断成功。
6. **完成判定**：同时验证成功状态、输出文件存在、文件可解析和记录数符合预期。
7. **质量检查**：检查必填字段、重复项、语言/Domain 枚举、空文本、字符集和样本分布。
8. **版本登记**：记录输入、输出、配置、工具版本和质检结果之间的关系。

## 失败处理

- 已有任务运行时不应覆盖或并发写入同一输出。
- 只有状态标记而没有有效输出文件，不能判定成功。
- 输出文件存在但结构校验失败，应标记为失败或待复核。
- 重跑必须使用新的运行标签，或明确记录对原运行的恢复关系。

## 与当前质量 Agent 的边界

当前 Agent 可以分析生成后的结构化质量数据、发现契约问题并保存版本化修正；它不负责登录训练机器、执行远程脚本或管理 SSH 凭据。
